### 1. 程式用途
本程式主要用於處理未經整理的聚餐原始文字資料，並進行自動化帳務試算。具體功能包含：
* **字串清理與格式化：** 去除活動名稱前後多餘空白並統一轉為小寫；移除餐費字串中的幣別符號（`NT$`）、千分位逗號（`,`）與空白字元。
* **資料型別轉換：** 將清理後的餐費字串轉換為浮點數（`float`），並將分攤人數字串轉換為整數（`int`），以便進行後續數學運算。
* **帳務與預算試算：** 依據原始餐費計算 $10\%$ 服務費，扣除折價券金額後得出應付總額，再除以人數算出每人平均分攤費用，最後以布林值（`bool`）判斷每人費用是否超出預算上限。

## 三、 問題回答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？
因為加上引號的 `"4"` 在 Python 中是「字串（`str`）」，無法直接進行數學除法運算（`total_amount / people_count`），直接相除會產生 `TypeError` 錯誤。所以必須先用 `int("4")` 轉成整數數字，才能順利計算每人分攤的金額。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
* **應付總額：** 會變成 **$1210$ 元**（計算方式：$(1200 - 100) \times 1.1 = 1210$ 元）。
* **不同的原因：** 因為計算服務費的基準（母數）變小了。題目原本是用原價 $1200$ 元算服務費（$120$ 元），先扣折價券後則變成用 $1100$ 元算服務費（$110$ 元），折價券的 $100$ 元也一起免除了 $10\%$ 服務費，所以總額會比原本少 $10$ 元。
